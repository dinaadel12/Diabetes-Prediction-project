Diabetes Prediction using Deep Learning

This project focuses on predicting whether a person has diabetes or not using medical data and Deep Learning techniques. The model is designed to support early detection and assist in medical decision-making.

Problem:

Diabetes is a life-threatening disease that requires early diagnosis. The challenge is to accurately classify patients based on medical features to determine whether they are diabetic or non-diabetic.

Approach:

Data preprocessing (handling missing values and feature scaling).
Built a Deep Learning classification model (Neural Network).
Optimized the model to improve performance and reduce loss.
Evaluated the model using accuracy and loss metrics.

Results:
Achieved 99.79% accuracy with a loss of 0.0442.
The model showed excellent performance in classifying diabetes cases.

Tools & Technologies:

Python, Pandas, NumPy, TensorFlow, Scikit-learn, Deep Learning
